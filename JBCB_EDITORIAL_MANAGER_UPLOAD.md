## Confirmed cause of the failed portal PDF

Page 29 of `JBCB-1505_R1.pdf` reports:

```text
! LaTeX Error: File `bibliography_jbcb.bbl' not found.
l.1130 \input{bibliography_jbcb.bbl}
! ==> Fatal error occurred, no output PDF file produced!
```

The log shows that the portal loaded `ws-jbcb.cls` and all six figures before
stopping at the bibliography. Uploading `references_jbcb.bib` does not satisfy
an explicit `\input{bibliography_jbcb.bbl}` command. The old ZIP contained the
required `.bbl`, but the current attachment list in the screenshots did not.
Duplicate-filename warnings are a separate concern: the portal says it will
use the first copy, potentially retaining an older manuscript or figure.
